## Структура проекта
- `README.md` — файл документации проекта.
- `payment-form.html` — платёжная форма (разметка).
- `payment-form.css` — стили платёжной формы.
- `payment-form.js` — логика формы: маски ввода, валидация (алгоритм Луны), имитация оплаты.

## Платёжная форма
Поля формы: **имя**, **фамилия**, **email**, **номер карты**, **срок действия**, **CCV**.

Функциональность:
- Маски ввода: номер карты (`XXXX XXXX XXXX XXXX`), срок действия (`ММ/ГГ`), CCV — только цифры.
- Автоопределение платёжной системы (Visa, Mastercard, МИР, Amex).
- Валидация всех полей: имя/фамилия (буквы, от 2 символов), корректный email, 16 цифр и проверка по алгоритму Луны, непросроченный срок действия, CCV 3–4 цифры.
- Имитация обработки платежа с сообщением об успешной оплате или об ошибках.

Открыть форму можно напрямую в браузере или через локальный сервер:
```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000/payment-form.html
```
